# 사내 통합 이메일 시스템 - MVP 프로토타입

## MVP 정의

> 공공기관 웹메일 사용자가 첨부파일 있는 메일을 수신할 때, 별도의 망 전송 프로그램 없이
> **'보내기' 한 번으로 내부망 전송까지 자동 처리되는 흐름**을 보여주는 프로토타입.

## 실행 방법

별도 설치나 서버 없이, `index.html` 파일을 더블클릭해서 브라우저로 열면 바로 동작합니다.

## 구현된 핵심 흐름

1. **로그인** — 사원번호/비밀번호 입력 후 로그인 1회 (OTP는 SSO에 통합된 것으로 간주, 별도 재로그인 절차 없음)
2. **받은메일함** — 첨부파일이 있는 메일과 없는 메일이 섞인 목록 (mock 데이터 5건)
3. **메일 상세** — 첨부파일이 있는 메일에는 **"내부망으로 전송"** 버튼 노출
   - 버튼 클릭 시 별도 사유 입력 없이 즉시 전송 프로세스 시작
4. **전송 상태 타임라인** — 승인자용 화면 없이, 신청자 화면에서 아래 단계가 자동으로 진행됨
   - 전송 요청 생성 → 상사 승인 → 보안담당자 승인 → 보안검사(DLP) 통과 → 내부망 전송 완료
5. **전송 이력** — 과거 + 방금 처리한 전송 건을 모아보는 목록 화면

## MVP 범위

### In Scope (이 프로토타입에 포함됨)
- 첨부파일 수신 → 버튼 한 번 → 내부망 전송 완결까지의 원스톱 흐름
- 승인 단계를 포함한 전체 프로세스의 시각적 시뮬레이션(타임라인)
- 로그인, 받은메일함, 메일 상세, 전송 이력 화면

### Out of Scope (이 프로토타입에서는 다루지 않음)
- 실제 이메일 송수신, 계정/서버/DB (모든 데이터는 JS 코드 내 mock 데이터)
- 상사/보안담당자용 별도 승인자 화면 (자동 시뮬레이션으로 대체)
- 전송 사유 입력, 반려 처리 등 예외 흐름
- 검색, 라벨, 코멘트/멘션, 중요도 태깅 등 PRD의 다른 기능(P1~P2)
- 모바일 반응형 대응 (데스크탑 화면 기준으로만 제작)

## 기술 스택

순수 HTML/CSS/JS, `index.html` 단일 파일 (스타일/스크립트 인라인 포함). 빌드 도구나 백엔드 없음.
